# Customer Churn Intelligence Platform

## 📌 Project Overview
The Customer Churn Intelligence Platform is a data analytics project designed to analyze customer churn, identify churn patterns, and understand revenue at risk. It uses Python, SQL, and Power BI to transform customer data into meaningful business insights.

## 🎯 Objectives
- Analyze customer churn patterns.
- Understand customer demographics and contract types.
- Identify factors associated with customer churn.
- Analyze revenue at risk.
- Present insights through interactive Power BI dashboards.

## 🛠️ Tools & Technologies
- **Python:** Data understanding, data cleaning, and exploratory data analysis (EDA)
- **Pandas:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization
- **SQL / MySQL:** Customer data queries and churn analysis
- **Power BI:** Dashboard creation and business reporting
- **CSV:** Dataset storage

## 🔍 Project Workflow
1. Understand the customer dataset.
2. Clean and prepare the data using Python.
3. Perform exploratory data analysis (EDA).
4. Analyze customer churn using SQL.
5. Identify business insights and revenue at risk.
6. Build Power BI dashboards to communicate findings.

## 📊 Key Analysis Areas
- Customer churn distribution
- Churn by customer demographics
- Churn by contract type and service-related factors
- Revenue at risk
- Customer segments that may need retention strategies

## 💡 Business Value
The analysis helps businesses understand customer churn patterns, identify potentially at-risk customer segments, and support data-driven customer retention decisions.

## 📁 Dataset
The project uses a 5,000-customer dataset. Review the dataset and its data dictionary, if available, before interpreting individual columns. If using simulated data, treat the results as practice analysis rather than actual company performance.
